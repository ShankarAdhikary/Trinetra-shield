# TRINETRA Icon Assets

This folder contains icon assets for the TRINETRA Chrome extension.

## Required Icons

- `icon16.png` - 16x16 pixels (toolbar)
- `icon32.png` - 32x32 pixels (Windows taskbar)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Design Guidelines

The TRINETRA icon represents the "third eye" concept:
- Primary color: #4A90E2 (blue)
- Accent color: #F5A623 (golden/amber)
- Background: Transparent or white

## Creating Icons

1. Create a master icon at 512x512 pixels
2. Export to required sizes using your design tool
3. Save as PNG with transparency
